## 문서끼리 다를 때

1. 파트 안의 일은 그 파트의 설계서가 맞다.
2. 파트 사이의 약속(필드 이름, 유형 값, 지표 정의)은 통합본이 맞다. 통합본이 틀렸으면 통합본을 고치고 버전을 올린다.
3. 아직 정해지지 않은 것은 통합본 11.1에 있다.

## 이름 규칙

`종류_파트번호_파트이름_v버전.확장자` (예: `설계서_3_GenAI_STT_v0.9.pdf`). 파트 번호는 0 전체, 1 백엔드, 2 프론트엔드, 3 GenAI·STT, 4 RPA다.

통합본과 ④ 설계서 본문에는 `설계서\…`, `통합본\…`처럼 작성자 PC의 폴더 이름이 남아 있다. 이 저장소에서는 모두 `docs/` 아래에 있다.
