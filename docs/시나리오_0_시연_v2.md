| 상태 | 초안. 화 18:00 MVP가 끝난 뒤 실제로 되는 것에 맞춰 고친다. v2에서 ④의 시작 방식을 큐 신호에서 시간 트리거(1분)로 바꿨다(강사 피드백, 11/24). |

보여 줄 것은 "녹취 파일을 넣으면 분류, 요약, 저장, 엑셀·웹 갱신이 사람 손 없이 끝난다"이다. 근거: 통합본 1장(목표), 4장(흐름), 5장(우선순위).

## 시작 전 준비

- [ ] 서버가 시연 노트북에서 떠 있고, 웹과 봇 PC에서 접속된다.
- [ ] Asset `BACKEND_BASE_URL`이 시연 노트북의 주소다.
- [ ] 시연 데이터가 들어 있다(seed 또는 미리 처리한 통화).
- [ ] 시연에 쓸 음성 파일 2~3개를 따로 둔다. 미리 처리하지 않은 것이어야 한다(같은 파일은 409로 건너뛴다).
- [ ] 엑셀 `콜센터_엑셀_최신.xlsx`를 닫아 둔다. 열려 있으면 봇이 덮어쓰지 못하고 1분마다 날짜시각이 붙은 파일을 만든다. 화면에 띄울 때는 복사본을 연다.
- [ ] 봇 PC가 켜져 있고 로그인되어 있다. ④의 시간 트리거가 켜져 있고 Orchestrator의 Jobs에 1분마다 Successful이 쌓인다.
- [ ] 처리 시작 방식(가져가기 또는 Job 시작)이 하나로 정해져 있다.

## 안 될 때

| 상황 | 대신 |
|---|---|
| 봇이 현장에서 실패한다. | 미리 처리해 둔 통화와 seed 데이터로 2, 4, 5, 6번을 보여 준다. |
| 서버에 접속되지 않는다. | 봇 PC에서 서버를 띄우거나 휴대폰 핫스팟으로 같은 네트워크에 붙인다. |
| Job 시작이 안 된다. | 가져가기 방식으로 7번을 보여 주고, Job 시작은 11번에서 설명한다. |
| ④의 시간 트리거가 돌지 않는다(봇 PC 로그아웃, 무인 실행 문제). | 봇 PC의 Assistant나 Studio에서 ④를 직접 실행한다. |
| 챗봇 AI 방식이 안 된다. | 규칙 방식으로 보여 준다. |
| 엑셀 파일이 열려 있어 덮어쓰지 못한다. | 봇이 다른 이름으로 저장한 파일 가운데 가장 최근 것을 연다. |
