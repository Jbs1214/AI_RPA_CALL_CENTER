# 콜센터 AI·RPA 비서 UI/UX 디자인 규칙 (`DESIGN.md`)

이 문서는 웹 대시보드(`frontend/`)의 화면 규칙이다. 화면 코드를 고치기 전에 읽고 따른다. 값은 Vapor 디자인 시스템의 공개 배포 토큰(라이트·다크)을 옮긴 것이고, 이 프로젝트에 맞게 줄였다. 이 디자인 시스템의 이름과 패키지는 화면의 글자나 클래스 이름에 쓰지 않는다.

흰 카드와 1px 보더로 영역을 나누는 담백한 B2B 관리자 화면이 기준이다. 라이트가 기본이고 다크도 같은 규칙으로 지원한다.

## 1. 하지 말 것

- 그라데이션, 글래스·블러, 네온 글로우, 질감, 장식 일러스트를 쓰지 않는다.
- 패널과 카드에 `box-shadow`를 주지 않는다. 그림자는 떠 있는 면(차트 말풍선, 드롭다운, 팝업)에만 쓴다.
- 아이콘 뒤에 색 원형 배경을 깔지 않는다. 이모지를 쓰지 않는다.
- 올렸을 때(hover)와 눌렀을 때(press)에 크기를 바꾸지 않는다. 8%, 16% 오버레이만 얹는다.
- 서버에 없는 값(대기 호, 봇 가동 토글 등)을 화면에 지어 넣지 않는다.

## 2. 디자인 값

값은 `src/styles/tokens.css`의 변수로만 쓴다. 화면 코드에 색 코드를 직접 쓰지 않는다. antd 색(`src/theme/ThemeProvider.tsx`)은 같은 값으로 맞춘다.

| 용도 | 라이트 | 다크 | 변수 |
| --- | --- | --- | --- |
| 페이지 바탕 | `#F4F4F4` | `#1F1F1F` | `--color-bg` |
| 패널, 사이드바 | `#FFFFFF` | `#282828` | `--color-surface` |
| 표 머리, 눌린 면 | `#FAFAFA` | `#363636` | `--color-elevated` |
| 1px 보더 | `#E1E1E1` | `#474747` | `--color-line` |
| 제목, 핵심 수치 | `#262626` | `#FAFAFA` | `--color-text` |
| 본문, 레이블 | `#4C4C4C` | `#BEBEBE` | `--color-text-sub` |
| 시각, 힌트 | `#767676` | `#898989` | `--color-muted` |
| 강조(CTA) | `#2A72E5` | `#368AED` | `--color-accent` |
| 올렸을 때 오버레이 | 글자색 8% | 글자색 8% | `--hover-bg` |

상태 뱃지는 옅은 면과 진한 글자의 한 가지 모양이다(테두리 없음).

- 정상, 완료: 라이트 `#BBECD7` 면 + `#00583A` 글자, 다크 `#003F23` + `#5DD3AA`
- 주의: 라이트 `#FFD9C8` + `#9E0000`, 다크 `#750000` + `#FBAC88`
- 오류, 실패: 라이트 `#FFD8D7` + `#9E0006`, 다크 `#750000` + `#FFA7A6`
- 수치 글자만 칠할 때는 `--ok-fg`, `--wait-fg`, `--err-fg`를 쓴다.

## 3. 글꼴과 숫자

- 화면 글꼴은 Pretendard, 숫자는 Inter다.
- 바뀌는 숫자(건수, 비율, 시각)는 `font-variant-numeric: tabular-nums`를 쓴다.
- 굵기는 400, 500, 700만 쓴다(600은 쓰지 않는다).
- 크기: 본문 14px(줄높이 22px, 자간 -0.1px), 작은 글자 12px(줄높이 18px), 패널 제목 14px/700, 큰 수치 24px/700.

## 4. 모양과 간격

- 모서리는 8px 하나다(패널, 버튼, 입력창, 뱃지). 원형은 점과 아바타에만 쓴다.
- 컨트롤 높이는 32px(보통), 모바일에서 눌러야 하는 것은 40px 이상으로 한다.
- 간격은 2px 단위다. 패널 안쪽 16px(모바일 12px), 패널 사이 16px.
- 아이콘은 Lucide, 16px, `strokeWidth` 1.5로 통일한다.
- 포커스는 2px 바깥선(`--color-text`)을 항상 보이게 둔다.

## 5. 화면 구조

- 왼쪽에 220px 고정 사이드바(오른쪽 1px 보더), 위에 48px 헤더, 나머지가 본문이다.
- 사이드바 메뉴는 본문의 영역으로 이동하는 링크다.
- 헤더 왼쪽은 현재 경로, 오른쪽은 서버 상태 점과 라이트/다크 버튼이다. 상태는 `GET /health`의 실제 응답이다.
- 본문은 왼쪽 약 2/3(요약 지표, 통화 목록), 오른쪽 약 1/3(업로드, 차트)이다.
- 1200px 아래에서는 한 열로 쌓고, 768px 아래에서는 사이드바를 위쪽 가로 메뉴로 바꾼다. 하단 탭바는 챗봇 버튼과 겹쳐서 쓰지 않는다.

## 6. 상태 표시

- 빈 상태: 빈 박스 대신 선 아이콘과 한 줄 안내를 둔다.
- 불러오는 중: 회전 스피너 대신 스켈레톤을 쓴다.
- 처리 중: 뱃지 앞 점에만 은은한 `pulse`를 준다.
- 버튼은 Primary(화면의 핵심 한 곳만), Secondary(보더), Ghost(투명) 세 단계다.
- 현재 쪽 번호는 채운 원색이 아니라 옅은 파랑 면(`--accent-weak`)과 진한 파랑 글자(`--accent-strong`)다.

## 7. 차트

- 막대와 고리는 단색이다. 유형 색은 `categoryColor.ts`에 있고 팔레트의 중간 단이다.
- 막대 모서리는 4px 이하, 눈금선은 보더 색, 올렸을 때 배경은 `--hover-bg`다.
- 차트 말풍선은 떠 있는 면이라 그림자(`--shadow-lift`)를 쓴다.
