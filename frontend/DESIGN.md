# 콜센터 AI·RPA 비서 UI/UX 디자인 규칙 (`DESIGN.md`)

이 문서는 웹 대시보드(`frontend/`)의 화면 규칙이다. 화면 코드를 고치기 전에 읽고 따른다. 원본 지침은 `airpa_ui_ux_claude.md`이고, 이 저장소의 화면에 맞게 줄였다.

실무자가 쓰는 고밀도 B2B 관리자 화면(Linear, Vercel, Raycast 같은 담백한 스타일)을 기준으로 한다. 어두운 단색 배경과 1px 보더로만 영역을 나눈다.

## 1. 하지 말 것

- 그라데이션, 네온 글로우, 발광 효과(`glow`, `drop-shadow`)를 쓰지 않는다.
- `box-shadow`로 영역을 나누지 않는다. 1px 보더와 배경 명도 차이만 쓴다.
- 모든 영역을 크게 둥근 카드로 감싸지 않는다. 패널은 8px 모서리다.
- 아이콘 뒤에 색 원형 배경을 깔지 않는다.
- 이모지를 제목, 메뉴, 버튼, 뱃지에 쓰지 않는다.
- 장식용 그래픽(3D 캐릭터, 배경 웨이브)을 넣지 않는다.
- 추상적인 홍보 문구를 쓰지 않는다. 콜센터 현업 용어를 쓴다.
- 서버에 없는 값을 화면에 지어 넣지 않는다(대기 호, 봇 가동 토글 등). 실제 데이터가 있는 것만 보여 준다.

## 2. 디자인 값

값은 `src/styles/tokens.css`의 변수로만 쓴다. 화면 코드에 색 코드를 직접 쓰지 않는다. 테마는 다크 하나다.

| 용도 | 값 | 변수 |
| --- | --- | --- |
| 전체 배경 | `#09090B` | `--color-bg` |
| 패널, 사이드바 | `#111114` | `--color-surface` |
| 호버, 선택, 모달 | `#18181B` | `--color-elevated` |
| 기본 보더 | `rgba(255,255,255,0.08)` | `--color-line` |
| 강조 보더 | `rgba(255,255,255,0.18)` | `--color-line-strong` |
| 제목, 핵심 수치 | `#FAFAFA` | `--color-text` |
| 본문, 레이블 | `#A1A1AA` | `--color-text-sub` |
| 시각, 힌트 | `#52525B` | `--color-muted` |
| 강조(CTA 한 곳) | `#3B82F6`, 호버 `#2563EB` | `--color-accent` |

상태 색은 뱃지와 상태 점에만 쓴다.

- 정상, 완료: 글자 `#34D399`, 배경 `rgba(16,185,129,0.10)`, 보더 `rgba(16,185,129,0.22)`
- 대기, 주의: 글자 `#FBBF24`, 배경 `rgba(245,158,11,0.10)`, 보더 `rgba(245,158,11,0.22)`
- 오류, 실패: 글자 `#FB7185`, 배경 `rgba(244,63,94,0.10)`, 보더 `rgba(244,63,94,0.22)`

## 3. 글꼴과 숫자

- 화면 글꼴은 Pretendard, 숫자·시각·ID는 JetBrains Mono다.
- 한글 제목은 `letter-spacing: -0.025em`이다.
- 바뀌는 숫자(건수, 비율, 시각)는 `font-variant-numeric: tabular-nums`를 쓴다.
- 크기: 페이지 제목 18px/600, 패널 제목 13px/600, 본문 13px/400(행간 1.5), 뱃지 11~12px/500.

## 4. 모양과 간격

- 모서리: 패널 8px, 버튼·입력창 6px, 뱃지·태그 4px.
- 간격: 붙어 있는 요소 4~8px, 패널 사이 12~16px, 패널 안쪽 16px(모바일 12px).
- 아이콘은 Lucide, 16px, `strokeWidth` 1.5로 통일한다.

## 5. 화면 구조

- 왼쪽에 220px 고정 사이드바(오른쪽 1px 보더), 위에 48px 헤더, 나머지가 본문이다.
- 사이드바 메뉴는 본문의 영역으로 이동하는 링크다(요약, 통화 목록, 업로드, 차트).
- 헤더 왼쪽은 현재 경로, 오른쪽은 서버 상태 점이다. 상태는 `GET /health`의 실제 응답이다.
- 본문은 균등하게 나누지 않는다. 왼쪽 넓은 영역(약 2/3)에 요약 지표와 통화 목록, 오른쪽 좁은 영역(약 1/3)에 업로드와 차트를 둔다.
- 1200px 아래에서는 한 열로 쌓고, 768px 아래에서는 사이드바를 없애고 상단 바와 가로 메뉴로 바꾼다. 하단 탭바는 챗봇 버튼과 겹쳐서 쓰지 않는다.

## 6. 상태 표시

- 빈 상태: 빈 박스 대신 단색 아이콘과 한 줄 안내를 둔다.
- 불러오는 중: 회전 스피너 대신 `#18181B` 톤 스켈레톤을 쓴다.
- 처리 중: 뱃지 왼쪽 6px 점에만 은은한 `pulse`를 준다. 다른 애니메이션은 넣지 않는다.
- 버튼은 세 단계다. Primary(화면의 핵심 한 곳만), Secondary(`#18181B` + 보더), Ghost(투명).

## 7. 차트

- 막대와 고리는 단색이다. 그라데이션을 쓰지 않는다.
- 유형 색은 상태 색과 같은 계열의 낮은 채도 값이다(`categoryColor.ts`).
- 모서리는 4px 이하로 작게 둥글린다. 눈금선은 보더 색을 쓴다.
