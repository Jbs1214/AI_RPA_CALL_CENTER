# 콜센터 AI·RPA 비서 UI/UX 디자인 규칙 (`DESIGN.md`)

이 문서는 웹 대시보드(`frontend/`)의 화면 규칙이다. 화면 코드를 고치기 전에 읽고 따른다. 값은 Ridi 디자인 토큰(라이트·다크)에서 가져왔고, 이 프로젝트에 맞게 줄였다(시험 중인 기준이다). 이 디자인 시스템의 이름은 화면의 글자나 클래스 이름에 쓰지 않는다.

흰 바탕과 차가운 무채색 위에 하늘색 파랑 한 가지만 포인트로 쓰고, 표지·카드는 4px 모서리로 정돈한다. 블루는 크기가 아니라 빈도로 일한다. 라이트와 다크를 같은 규칙으로 지원한다.

## 1. 하지 말 것

- 그라데이션, 글래스·블러, 네온 글로우, 질감, 장식 일러스트를 쓰지 않는다.
- 패널과 카드에 `box-shadow`를 주지 않는다. 구분은 1px 선과 옅은 면으로 한다. 그림자는 떠 있는 면(차트 말풍선, 드롭다운, 팝업)에만 쓴다.
- 파랑을 위치·선택·핵심 행동 밖에 쓰지 않는다. 화면 대부분은 짙은 회색 글자와 회색 보조 글자, 흰 바탕이다.
- 아이콘 뒤에 색 원형 배경을 깔지 않는다. 이모지를 화면 요소에 쓰지 않는다.
- 서버에 없는 값(대기 호, 봇 토글, 서버 상태 표시 등)을 화면에 지어 넣지 않는다.

## 2. 디자인 값

값은 `src/styles/tokens.css`의 변수로만 쓴다. 화면 코드에 색 코드를 직접 쓰지 않는다. antd 색(`src/theme/ThemeProvider.tsx`)은 같은 값으로 맞춘다.

| 용도 | 라이트 | 다크 | 변수 |
| --- | --- | --- | --- |
| 페이지 바탕 | `#F5F5F5` | `#141414` | `--color-bg` |
| 패널, 사이드바 | `#FFFFFF` | `#202020` | `--color-surface` |
| 표 머리, 눌린 면 | `#FAFAFA` | `#2C2C2C` | `--color-elevated` |
| 1px 보더 | `#E6E6E6` | `#373737` | `--color-line` |
| 제목, 본문 | `#141414` | `#F5F5F5` | `--color-text` |
| 보조 글자 | `#787878` | `#A5A5A5` | `--color-text-sub` |
| 시각, 힌트 | `#A5A5A5` | `#787878` | `--color-muted` |
| 메인 색(파랑) | `#1E9EFF` | `#1496E6` | `--color-accent` |
| 올렸을 때 오버레이 | 검정 4% | 흰색 8% | `--hover-bg` |

다크의 보조 글자와 힌트는 원본(`#666666`, `#505050`)이 어두운 바탕에서 너무 흐려서 한 단계 밝게 잡았다.

상태 뱃지는 옅은 면과 진한 글자의 한 가지 모양이다(테두리 없음).

- 정상, 완료: 면 `#EBF9F1`, 글자 `#288852` (다크 면 `#1F6940`, 글자 `#61CC90`)
- 주의: 면 `#FFF1E6`, 글자 `#B24E00` (다크 면 `#8A3D00`, 글자 `#FC9E54`)
- 오류, 실패: 면 `#FCEBEB`, 글자 `#DC3232` (다크 면 `#791C1C`, 글자 `#EFA1A1`)

## 3. 글꼴과 숫자

- 글꼴은 Pretendard 하나다(`--font-ui`). 숫자도 같은 글꼴이다.
- 바뀌는 숫자(건수, 비율, 시각)는 `font-variant-numeric: tabular-nums`를 쓴다.
- 자간은 크기 × -0.01이다(14px는 -0.14px). 본문 14px, 줄높이 22px.
- 굵기는 400과 700을 쓴다(로고 글자만 800). 페이지 제목 20px/700, 패널 제목 14px/700, 큰 수치 24px/700.

## 4. 모양과 간격

- 모서리: 패널·업로드 띠·지표 패널 12px, 버튼·입력창과 패널 안쪽 칸(끌어놓기 칸) 8px, 뱃지·태그 6px, 선택 알약 99px. 바깥은 12, 그 안쪽은 8로 맞춘다.
- 컨트롤 높이는 32px. 모바일에서 눌러야 하는 것은 40px 이상으로 한다.
- 간격은 4px 단위다(2, 6, 10px도 쓴다). 패널 안쪽 16px(모바일 12px), 패널 사이 16px.
- 아이콘은 Lucide, 16px, `strokeWidth` 1.5로 통일한다.
- 모션은 200ms `ease` 하나다(`--motion`). 라이트/다크를 바꾸는 동안에는 `theme-switching` 클래스로 전환 효과를 잠깐 끈다(깜빡임 방지). 처음 열 때는 `index.html`의 작은 스크립트가 저장된 테마를 먼저 적용한다.
- 포커스는 2px 바깥선(`--color-text`)을 항상 보이게 둔다.

## 5. 화면 구조

- 본문은 최대 1280px 폭으로 화면 가운데에 놓는다(`--page-max`). 넓은 화면에서는 양옆에 여백이 생기고, 위쪽 메뉴 줄 안쪽도 같은 폭에 맞춘다.
- 페이지: `/` 대시보드, `/stats` 통계(차트 4개). 통화 한 건의 상세는 목록에서 눌러 여는 옆 패널(드로어)이고, 항목(통화 정보, 수정, 대화)을 위에서 아래로 쌓는다. 챗봇이 여는 상세도 같은 패널이다.
- 위에 56px 메뉴 줄(`AppHeader`)은 흰 면(패널 색) 위에 아래 1px 선만 둔다. 왼쪽부터 로고 "AIRPA", 메뉴(대시보드, 통계), 오른쪽 끝의 라이트/다크 버튼이다. 로고는 굵게(800) 촘촘하게(자간 -0.05em) 쓰고 "AI" 두 글자만 메인 파랑이다. 메뉴는 보통 때 회색, 현재 메뉴는 진한 글자와 줄 아래 3px 파란 막대다. 줄 안쪽은 본문과 같은 폭·좌우 여백에 맞춘다. 서비스 소개 문구나 서버 상태 표시는 넣지 않는다.
- 메인(대시보드)은 위에서 아래로 지표 6칸 → 업로드 띠 → 통화 목록이다. 업로드 띠는 옅은 파랑 면(모서리 12px) 위에 왼쪽 제목·설명·알약 버튼(`음성 파일 선택`, `직접 입력`, 파일을 담으면 `업로드 시작`·`초기화`), 오른쪽에 흰 면의 점선 끌어놓기 칸을 놓는다. 담은 파일은 띠 안 아래 줄로 펼쳐지고, 1000px 아래에서는 한 열로 쌓인다.
- 엑셀 내보내기는 통화 목록 패널 제목 줄 오른쪽 끝의 버튼이고, 목록과 같은 조건으로 서버의 내보내기(API 7)를 받는다.
- 목록 필터는 한 줄에 자주 쓰는 것(검색, 유형, 상태, 기간)만 둔다. 담당자·고객사·후속조치·검토 필요는 상세 조건 팝오버에 모으고, 걸린 조건 수를 버튼 숫자로 보여 준다. 초기화는 조건이 걸렸을 때만 나타난다.
- 지표 6칸은 엑셀 대시보드와 같은 보조 설명을 수치 옆에 작게 붙인다: 분석된 통화 "완료 통화 기준", 후속조치·검토 필요 "전체의 N%", 불만 통화 "후속조치 N건", 불만 비율 "N건 / M건", 가장 많은 유형 "N건".
- 지표 수치는 기본이 글자색이다. 사람이 처리해야 하는 것(후속조치 필요, AI 결과 검토 필요)이 1건 이상일 때만 빨갛게 한다. 불만 통화·불만 비율처럼 알려 주는 수치는 빨갛게 하지 않는다.
- 하단 탭바는 챗봇 버튼과 겹쳐서 쓰지 않는다.
## 6. 상태 표시

- 빈 상태: 빈 박스 대신 선 아이콘과 한 줄 안내를 둔다.
- 불러오는 중: 회전 스피너 대신 스켈레톤을 쓴다.
- 처리 중: 뱃지 앞 점에만 은은한 `pulse`를 준다.
- 파랑을 쓰는 곳은 세 군데다. 현재 메뉴(파란 글자, 배경 없음), 선택된 것(파란 면 + 흰 글자, 예: 현재 쪽 번호), 핵심 버튼(파란 면 + 흰 글자).
- 흰 글자와 파란 면의 대비는 약 2.8:1로 낮다(원본의 관행). 글자는 굵게 두고, 작은 글자에는 쓰지 않는다.

## 7. 차트

- 일자별 차트는 엑셀 요약 시트와 같게 통화가 있는 날 중 최근 14일만, 날짜 오름차순으로 보여 준다.

- 막대와 고리는 단색이다. 유형 색은 `categoryColor.ts`에 있다(질의 파랑, 불만 레드, 건의 옐로, 교육 내용 그린, 기타 문의 회색).
- 담당자별 차트의 "통화 건수" 막대는 메인 파랑을 쓴다.
- 막대 모서리는 4px 이하, 눈금선은 옅은 회색, 올렸을 때 배경은 `--hover-bg`다.
- 차트 말풍선은 떠 있는 면이라 그림자(`--shadow-lift`)를 쓴다.
