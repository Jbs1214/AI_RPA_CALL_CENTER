# rpa-report 지침

④ UiPath RPA 코어·보고서(담당: 주영)의 작업 폴더에 적용된다. 공통 규칙은 루트의 `CLAUDE.md`에 있다.

큐에서 신호를 받아 서버의 완료 통화 목록으로 4시트 엑셀을 다시 만드는 UiPath 봇이다. 큐는 신호로만 쓰고, 엑셀에 쓰는 값은 전부 서버 목록에서 받는다. 엑셀은 매번 완료 통화 전체로 다시 만든다.

## 참고할 곳

필요할 때 직접 읽는다. 이 파일과 다르면 아래 문서가 맞다.

- 처리 순서와 실패 시 처리: `docs/설계서_4_RPA_v5.md` 3장, 8장
- 큐 항목과 서버 목록의 형식: 설계서 4장
- 템플릿의 시트, 표, 수식, 차트 범위: 설계서 5장
- 통화 대장 12열의 변환 규칙: 설계서 6장
- 템플릿 v3의 요약 시트 목록과 차트: 설계서 7장
- Orchestrator 세팅(큐, Asset, 외부 앱, 무인 실행): 설계서 9장
- 시험 순서와 기대값: 설계서 11장, 이 폴더의 `README.md`
- 지표 정의(웹과 같아야 한다): `docs/제품요구사항정의서_v1.8.md` 8장

## 설계 규칙

- 서버에는 읽기만 한다. 호출은 `GET /api/calls?status=DONE&include_transcript=true&size=200` 하나이고, 받은 건수가 응답의 `total`이 될 때까지 `page`를 올린다.
- 큐 항목의 값은 로그에만 쓴다. 엑셀 값으로 쓰지 않는다. `status`가 `FAILED`인 항목도 들어온다.
- 큐에 여러 건이 있어도 모두 꺼낸 뒤 엑셀은 한 번만 다시 만든다.
- 엑셀은 엑셀 프로그램으로 템플릿을 열어 쓴다. 파일을 새로 만들어 내는 활동이나 라이브러리는 차트와 슬라이서를 잃을 수 있어 쓰지 않는다.
- 템플릿(`templates/콜센터_엑셀_템플릿_v3.xlsx`)은 고치지 않고 복사본에 쓴다. 통화 대장은 `A2:L1000`의 값만 지우고 채운다. 시트나 행을 지우지 않는다.
- 통화 대장 시트에만 쓴다. 요약 시트와 대시보드에는 쓰지 않는다. 담당자·통화일·고객사 목록과 차트는 템플릿의 수식이 만든다.
- 요약 시트의 `J:T`열(계산용, 숨김)과 이름 정의(`chtAgentA` 등)는 고치지 않는다. 차트가 이 이름을 가리킨다.
- 통화일시는 한국 시간으로 바꾼 날짜 값으로 쓴다. 문자열로 쓰면 일자별 집계가 0이 된다.
- 후속조치와 검토 필요는 `Y`/`N`으로 쓴다. 통화 내용은 32,000자에서 자른다.
- 담당자나 고객사가 `미확인`인 통화도 그대로 쓴다.
- 엑셀을 만들다 실패하면 기존 `콜센터_엑셀_최신.xlsx`를 그대로 두고, 꺼낸 큐 항목을 실패로 표시한다.
- 서버 연결 실패와 5xx는 5초 간격으로 3회 재시도한다. 422는 재시도하지 않는다.
- 큐 이름, 경로, 쪽 크기, 재시도 횟수는 워크플로우에 직접 쓰지 않고 설정 파일이나 Asset에서 읽는다(`config.example.json`).
- 서버 주소와 API 키는 Asset `BACKEND_BASE_URL`, `BACKEND_API_KEY`에서 읽는다.

## 시험

- 서버가 없어도 `testdata/`의 가짜 JSON으로 통화 대장 쓰기를 먼저 확인한다. 기대값은 `README.md`에 있다.
- 템플릿이나 쓰기 규칙을 바꾸면 `tools/check_template.py`로 seed 14건과 경계 사례 6건을 다시 확인한다. 지표 6개와 담당자별·일자별·고객사별 합계가 분석된 통화와 같아야 한다.
- 템플릿을 스크립트로 다시 만들었으면 Excel에서 열어 차트 4개가 보이는지 확인한다. 스크립트는 차트가 열리는지까지는 확인하지 못한다.
- 웹과 숫자가 다르면 서버 통계(`GET /api/stats`)와 먼저 비교한다.

## 하지 말 것

- 로그에 통화 내용, 전화번호를 쓰지 않는다. 관리번호와 건수만 남긴다.
- 봇이 만든 엑셀, 엑셀 임시 파일, 실제 설정 파일(`config.json`)을 커밋하지 않는다.
- CLOVA Asset(`CLOVA_INVOKE_URL`, `CLOVA_SECRET_KEY`)은 ③의 것이다. 읽거나 바꾸지 않는다.
- 외부 앱의 Secret을 파일, 문서, 커밋, 대화방에 적지 않는다.
- 통화 대장의 열 순서와 머리글을 바꾸지 않는다. 서버의 엑셀 다운로드(API 7)와 같은 12열이다.

## 기록

- 설계가 바뀌면 `docs/설계서_4_RPA_v5.md`를 먼저 고치고 버전을 올린다. 이 파일과 `README.md`에 적힌 파일 이름도 같이 고친다.
- 다른 파트에 영향을 주는 변경(큐 이름, Asset, 엑셀 열)은 통합본도 함께 고친다.
